「FREEGO」事業の概要

1. 事業概要

「FREEGO」は、ユーザーが旅行を計画してから帰宅するまでのすべてのプロセスを一括で管理できる旅行プラットフォームです。 このサービスは、旅行者のニーズに応じて、最適な旅行プランを提供し、宿泊施設、交通手段、観光地、飲食店などを簡単に予約できる仕組みを提供します。 さらに、全国の観光地や飲食店、宿泊施設などと提携しており、ユーザーはその場で最適なプランを選択し、手軽に予約・決済を完了できます。

2. 主要な事業展開の概要

FREEGOは、「旅行計画」「予約・決済」「旅行中のサポート」「旅行後のフォローアップ」という4つの主要フェーズを通じて、顧客に包括的なサービスを提供します。 それぞれのフェーズにおいて、ユーザーに寄り添った機能を展開し、旅行体験を最大化することを目指しています。 また、地域の観光資源や飲食店、宿泊施設と提携し、地域経済の活性化にも貢献していきます。

・旅行計画機能：AIを活用して、ユーザーの希望に応じた旅行プランを自動生成し、最適な提案を行います。
・予約・決済機能：一括予約と決済が可能なシステムを構築し、ユーザーの手間を大幅に削減します。
・旅行中サポート：リアルタイムで旅行に関する情報提供やサポートを行い、快適な旅を実現します。
・旅行後のフォローアップ：旅行後に思い出を共有できる機能を提供し、次回の旅行に向けた提案も行います。

3. 事業方針

FREEGOのビジネスモデルは、旅行者に対する総合的なサポートと、事業者との緊密な連携により収益を確保します。 旅行者がFREEGOを通じて予約した際の手数料収入が主な収益源となり、その他に広告収益やプレミアムプラン、提携事業者からの紹介料なども収益化の手段として展開していきます。 これにより、持続可能で成長性の高いビジネスモデルの構築を目指します。

収益モデル：
・手数料収入：ユーザーがプラットフォームを通じて予約を行った際、宿泊施設や飲食店、観光施設から手数料を徴収します。
・広告収入：地域の観光施設や飲食店がFREEGO内に広告を掲載することで、広告収入を得ます。
・プレミアムプラン：有料会員向けに、特別な割引や優先予約などの特典を提供し、サブスクリプション収益を獲得します。
・提携事業者からの紹介料：FREEGO経由で予約された旅行者を提携事業者に紹介することで、紹介料を得ます。

イベント/在庫

FREEGOでは、全国各地で開催される主要イベントと連携し、イベント開催時には特別な旅行プランを提供します。 これにより、イベント参加者に対して宿泊や交通、観光施設の予約をワンストップで提供し、円滑な旅行体験をサポートします。 また、各地域における在庫（宿泊施設、飲食店、観光施設）を確保し、需要に応じた柔軟なサービス提供を実現します。

**PER

**PER（株価収益率）とは

「PER（株価収益率）」は、株価が利益の何倍かを示す指標です。 企業の成長性や収益性を評価する際に広く使われる指標であり、投資判断の重要な基準となります。

PER（株価収益率） = 株価 ÷ 1株当たり利益（EPS）

PERが高いほど、市場はその企業の将来的な成長を期待していることを意味します。 一方、PERが低い場合は、割安と判断されることもありますが、成長性が低いと評価されている可能性もあります。

PER 30倍の根拠と基準

FREEGOでは、事業の成長性と市場のポテンシャルを考慮し、PER 30倍を基準として設定しています。 これは以下のような企業類型において妥当とされる水準です。

PER 30倍が妥当な企業例：

  • ハイテク / テクノロジー企業（高成長期）
  • SaaSビジネス（クラウドサービス企業）
  • 市場シェア拡大中の企業（E-コマース / フィンテック）
  • バイオ / ヘルスケア企業
  • クリーンエネルギー企業（脱炭素テクノロジー企業）
  • AI関連企業
  • メディア / エンターテインメント企業
  • サブスクリプションビジネス
  • ゲーム / モバイルアプリ企業
  • 革新的スタートアップ
  • Spotify（音楽ストリーミング企業）
  • 医療機器 / MedTech企業
  • ロボティクス企業
  • Social Media（体験型ソーシャル企業サービス）

PERの比較と選択背景

PER 30倍を選択した理由：

FREEGOがPER 30倍を採用する理由は、以下の通りです。

  • 高成長期の企業として1～3年で事業を5倍以上に拡大する計画があること
  • インターネットビジネス（旅行×テクノロジー企業）としての成長性が高いこと
  • SaaSやPaaSと同様にプラットフォームを通じた収益モデルを採用していること

補足：PERの一般的な水準

  • 低PER（5～20倍）： 成熟企業や安定成長企業
  • 中PER（20～30倍）： 成長企業や市場拡大中の企業
  • 高PER（30～50倍以上）： 高成長企業や革新的技術を持つ企業

FREEGOは、旅行業界におけるプラットフォームビジネスとして、今後の市場拡大と収益成長が期待されるため、PER 30倍という水準が妥当であると判断しています。

**転換のインセンティブ

転換社債から株式への転換を促進するため、投資家に対して以下のインセンティブを提供します。 これにより、投資家と企業の双方にメリットがある仕組みを構築しています。

企業価値の向上（収益増加）の根拠

FREEGOの企業価値向上は、以下の要因によって実現されます。

  • 市場拡大： 旅行業界のデジタル化が進む中、FREEGOのプラットフォームは国内外での需要拡大が見込まれます。
  • 事業成長の加速化： 提携先の増加やサービスの多様化により、売上と収益が継続的に成長します。
  • 戦略的パートナーシップ： 大手旅行会社や観光施設、交通機関との連携を強化し、事業基盤を拡大します。

債権回収

  • 利息支払いと元本返済： 転換しない場合でも、定期的な利息収入が保証されます。

企業価値増加による株式価値の上昇

転換社債を株式に転換することで、以下の利益を享受できます。

  • 市場での評価向上： 企業の成長に伴い、株価が上昇することで、保有株式の価値が増加します。
  • 財務の健全化と成長の持続性： 安定した財務基盤と継続的な成長により、長期的な株価上昇が期待されます。
  • 転換条項による割引価格での転換権： 一定の条件下で、市場価格よりも有利な価格で株式に転換できる権利が付与されます。

透明性の高い情報開示

投資家の信頼を獲得し、適切な投資判断を支援するため、以下の情報開示を徹底します。

  • 定期的な業績報告と説明会の開催： 四半期ごとに業績報告を行い、投資家との対話の機会を設けます。
  • 四半期ごとの財務報告と事業進捗の詳細開示： 財務状況や事業の進捗状況を詳細に公開します。
  • 投資家向けIR資料の充実とwebサイトでの公開： IR情報を常に最新の状態で公開し、アクセスしやすい環境を整備します。
  • 経営陣との直接対話の機会（株主総会、説明会など）： 株主総会や個別説明会を通じて、経営陣と投資家の直接的なコミュニケーションを促進します。
  • 市場動向や業界トレンドに関する分析情報の提供： 業界全体の動向を分析し、FREEGOの位置づけを明確に示します。
  • リスク要因の明確な開示と対応策の説明： 事業に関するリスクを包み隠さず開示し、その対応策を具体的に説明します。

まとめ

転換社債（CB：Convertible Bond）は、投資家にとって柔軟な投資手段を提供します。 企業価値が増加した際には株式に転換して株価上昇の恩恵を受けることができ、転換しない場合でも利息収入を得られるという、二重のメリットを享受できます。

一方、企業側にとっても、成長段階において必要な資金を柔軟に調達でき、株式希薄化のリスクを抑えながら事業拡大を進めることができます。 このように、転換社債は投資家と企業の双方にとって Win-Win の関係を構築する仕組みとなっています。
