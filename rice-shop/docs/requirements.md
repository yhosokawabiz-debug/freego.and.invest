# 要件定義：自社プレミアムライス 通販サイト

`【要確認】` の箇所は事業側で決めて、このファイルを更新してから実装に入る。

## 1. 目的

- 自社ブランドのプレミアムライスを、モール（楽天・Amazon 等）を通さず直販する
- 定期便で継続売上をつくる
- ブランドの世界観を伝え、高価格帯でも選ばれる購入体験にする

## 2. 対象ユーザー

- 食にこだわる個人（自家消費・定期購入）
- 贈答用途（お歳暮・お中元・内祝い）【要確認：ギフト対応をどこまでやるか】

## 3. 商品

| 項目 | 内容 |
|---|---|
| 品種・銘柄 | 【要確認】現在はサンプル 4 品種 |
| 容量 | 2kg / 5kg / 10kg【要確認】 |
| 精米方法 | 白米・無洗米・7分づき・5分づき・玄米（品種ごとに選択肢を絞れる） |
| 価格 | 税込表示。1kg 単価 × 容量 × 容量係数（2kg 1.1 / 5kg 1.0 / 10kg 0.95）【要確認】 |
| 在庫 | 当面は品種ごとの在庫あり/なしのみ。数量管理はフェーズ 3 |

## 4. 購入形態

- 通常購入
- 定期便：毎月 / 隔月。通常価格から 5% オフ・送料無料【要確認】
  - 2 回目以降は自動決済 → 注文を自動作成
  - マイページでスキップ・解約・カード変更（フェーズ 2）

## 5. 配送

- 受注後に精米して発送。精米日をラベルに記載
- お届け希望日：注文の 3〜14 日後 / 時間帯：午前・14-16・16-18・18-20・19-21
- 送料：税込 5,000 円以上または定期便で無料、それ以外 990 円【要確認：離島・沖縄の扱い】
- 配送業者：【要確認】（ヤマト / 佐川 / 日本郵便）。送り状 CSV 出力が必要

## 8. 非機能要件

- カード情報は自社サーバーを通さない（Stripe Elements / Paidy のフォームのみ）→ PCI DSS は SAQ A 相当
- HTTPS 必須、秘密鍵はホスティングの環境変数で管理
- スマートフォンで快適に購入できること（購入の大半はスマホ想定）
- 想定ホスティング：Vercel + PostgreSQL（Neon / Supabase 等）【要確認】
