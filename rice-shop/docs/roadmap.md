# ロードマップ

各タスクの「Claude Code への指示」をそのまま貼り付ければ作業を始められる。
1 タスク = 1 ブランチ = 1 PR を基本にする。完了したら `[x]` にする。

---

## フェーズ 0：決済の実地確認（最優先）

### [ ] 0-1. テストキーで全決済を通す
**事前準備（人がやる）**：Stripe・Paidy のアカウント作成、テストキーを `rice-shop/.env` に設定、Stripe Dashboard で各支払い方法を有効化、Stripe CLI をインストール。

> Claude Code への指示：
> rice-shop を起動して、Stripe（カード・コンビニ・銀行振込）、定期便、Paidy の各決済をテストモードで 1 回ずつ通して。`npm run stripe:listen` で Webhook も受けて、注文ステータスが paid / awaiting_payment に正しく変わるか DB で確認し、問題があれば直して。

**完了条件**：全手段で注文が作られ、Webhook 後に正しいステータスになる。

## フェーズ 1：公開に必要な最低限

### [ ] 1-1. 商品データを本番の内容に差し替え
**事前準備**：商品名・産地・説明文・価格・容量・精米方法・商品写真を用意。

> Claude Code への指示：
> `docs/requirements.md` と添付の商品情報をもとに `src/lib/catalog.ts` の PRODUCTS を本番の商品に置き換えて。商品画像は `public/products/` に置いて表示できるようにして。価格ロジックを変える場合は catalog.test.ts も更新して。

### [ ] 1-2. 注文確認メール
> Claude Code への指示：
> Resend を使って、注文受付・支払い完了・発送完了のメールを送れるようにして。テンプレートは日本語で、注文番号・商品・金額・お届け日時・支払い方法ごとの案内（コンビニ番号や振込先は Stripe の情報から）を含めて。送信は Webhook／Paidy 確定のタイミングで、二重送信しないように。

### [ ] 1-3. 管理画面（受注一覧・発送登録）
> Claude Code への指示：
> `/admin` に管理画面を作って。ログインは環境変数で設定した管理者のみ（Basic 認証か Auth.js のメールリンクで十分）。機能は ①注文一覧（ステータス・支払い方法・お届け日で絞り込み）②注文詳細 ③精米済み・発送済みへのステータス変更と追跡番号入力 ④ヤマト B2 クラウド用の送り状 CSV 出力。発送済みにしたら発送メールを送って。

### [ ] 1-4. 本番環境（PostgreSQL + Vercel）
> Claude Code への指示：
> Prisma の provider を PostgreSQL に切り替えて、マイグレーションを `prisma migrate` 運用に変えて。Vercel にデプロイする手順と、必要な環境変数・Stripe Webhook の登録手順を README にまとめて。

### [ ] 1-5. 法務ページ・ブランドデザイン
**事前準備**：特商法の事業者情報、プライバシーポリシー文面、ロゴ・ブランドカラー・写真。

> Claude Code への指示：
> 特商法ページの【要記入】を埋めて、プライバシーポリシーページを追加して。トップページをブランドに合わせたデザイン（ヒーロー画像・こだわり・生産者紹介・定期便の訴求）に作り直して。スマホ表示を優先で。

## フェーズ 2：定期便・リピート強化

### [ ] 2-1. 会員登録・マイページ
> Claude Code への指示：
> メールリンクでログインできる会員機能を追加して。マイページで注文履歴を見られるようにして。購入時のゲスト注文は残し、同じメールで登録したら過去注文を紐づけて。

### [ ] 2-2. 定期便の管理
> Claude Code への指示：
> マイページから定期便のスキップ・お届け周期変更・解約・カード変更をできるようにして。カード変更と解約は Stripe Customer Portal を使ってよい。スキップは Stripe Subscription の pause_collection で実装して。

### [ ] 2-3. NP後払いの実装
**事前準備**：ネットプロテクションズと加盟店契約し、API 仕様書と接続情報を入手。

> Claude Code への指示：
> 添付の NP後払い API 仕様書に沿って `src/lib/np-atobarai.ts` の取引登録を実装して。審査保留の場合の与信結果取得、発送時の出荷報告（管理画面の発送登録と連動）、キャンセルも実装して。
